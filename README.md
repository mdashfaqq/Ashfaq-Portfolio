# Mohamed Ashfaq — Developer Portfolio

A premium futuristic portfolio showcasing my work as a **Full Stack Developer** and **Cybersecurity Enthusiast**. Built with modern web technologies, immersive animations, and interactive 3D experiences to highlight projects, skills, certifications, and professional achievements.

## ✨ Features

* Modern futuristic UI/UX
* Interactive 3D hero section
* Smooth animations with Framer Motion
* Responsive design for all devices
* Project showcase with live demos and source code
* Skills, experience, and certifications sections
* Contact form and social links
* Optimized performance with Vite

## 🛠️ Tech Stack

* React 19
* TypeScript
* Vite
* Tailwind CSS v4
* Framer Motion
* React Three Fiber
* Three.js

## 🚀 Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build for Production

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```
