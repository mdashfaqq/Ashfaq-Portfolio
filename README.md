# Mohamed Ashfaq — Portfolio

Premium futuristic portfolio for a **Full Stack Developer & Cybersecurity Enthusiast**.

## Stack

- React 19 + TypeScript + Vite
- Tailwind CSS v4
- Framer Motion
- React Three Fiber (3D hero)

## Run

```bash
npm install
npm run dev
```

## Sections

Hero · About · Skills · Experience · Projects · Certifications · Services · Contact

## Customize

Edit files in `src/data/` — `profile.ts`, `projects.ts`, `skills.ts`, etc.
